# avatar_libs —— 数字人素材库（运行时生成，不入 Git）

本目录是数字人（嘴型驱动）的**素材库**：每个子文件夹 = 一个人物，
内含 `manifest.json` + `frames\*.jpg`（闭嘴/张嘴关键帧序列）。

> 素材来自**真人说话视频**，属于个人形象数据，**不随仓库分发**。

## 如何新增人物

1. 启动数字人服务后打开**建库工具**：http://127.0.0.1:48620/web/preprocess.html
2. 上传一段该人物的说话视频（3~10 秒、正脸、光线均匀）
3. 一键生成嘴型图库 → 自动在 `avatar_libs\` 下新建人物文件夹
4. 在数字人主页 http://127.0.0.1:48620/web/index.html 加载该人物即可

## 可选素材

服务还兼容 4 张闭嘴→张嘴图片手动上传建库（`/api/upload`，见 `avatar_server.py`）。
