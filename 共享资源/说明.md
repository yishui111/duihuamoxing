# 共享资源说明

本目录说明三个子项目（对话系统 / 数字人 / 文字驱动语音）的**公共依赖**如何组织。

## 布局约定

三个子项目是**源码各自成目录**，但运行环境（Python 虚拟环境、模型、数据）放在**仓库根目录共享**，子项目脚本通过相对路径（`..\venv` 等）引用：

| 资源 | 位置（部署后） | 用途 | 谁在用 |
|------|----------------|------|--------|
| `venv\` | 仓库根目录 | Open WebUI 运行环境 + Python 解释器 | 对话系统、数字人 |
| `runtime\py312\` | 仓库根目录 | Python 3.12 + PyTorch 运行环境（GPT-SoVITS 用） | 文字驱动语音 |
| `runtime\ffmpeg\` | 仓库根目录 | 视频/音频转码 | 数字人（建库转码）、文字驱动语音（mp3 转码） |
| `data\open-webui\` | 仓库根目录 | 对话数据（聊天/记忆/知识库/SQLite/向量库） | 对话系统 |
| `data\ollama\models\` | 仓库根目录 | Ollama 模型权重（qwen2.5:7b、bge-m3） | 对话系统 |
| `data\tts.pid` | 仓库根目录 | TTS 服务 PID 记录（关闭用） | 文字驱动语音 |
| `log\` | 仓库根目录 | 各服务运行日志 | 全部 |

## 为什么这样放

- `venv` / `runtime` 体积巨大（合计超过 10GB），三个子项目各复制一份浪费磁盘且难以升级维护；
- 因此采用「**源码分目录、公共依赖共享**」的结构：想改哪个子项目进对应目录即可；根目录提供一键启动/关闭。

## 本仓库（Git）里没有这些大件

本仓库**只含源码/脚本/文档**。上面表格里的 `venv`、`runtime`、`data`、`log` 等目录
**不随 Git 分发**（见根目录 `.gitignore`），需要在新机器上按 `DEPLOY.md` 第 4 节创建并安装依赖。

## 一键启动 / 关闭

根目录的 `一键启动全部.bat` / `一键关闭全部.bat` 可同时拉起/关闭三个子项目；
`启动.bat` / `关闭.bat` 是单窗口全部启动/停止的另一种方式。
