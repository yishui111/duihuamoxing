一、核心逻辑与解耦原则（大白话版）
因为你家没有公网IP，运营商不给，所以传统的光猫端口映射行不通。你需要让家里的台式机主动向外网发起连接，利用 Cloudflare Tunnel 技术打通一条专用通道。

记住三个东西是互相独立的：

域名（905283.xyz） = 招牌，挂在云端的，永不消失。

隧道连接器（Docker 里的 cloudflared） = 传菜员，负责把外网请求转到你电脑的指定端口。

本地服务（你跑在 8080 端口的程序） = 厨师，负责处理请求、返回网页。

换台式机完全不影响，只要在新电脑上重新跑一下 Docker 命令（用同一个 Token），隧道就自动接上了。

三、模块二：本地服务器准备与自测（⏳ 待执行，当前步骤）
目标：先在台式机上跑一个服务，确保它能被本机访问，然后再暴露到外网。

📝 操作步骤
第一步：安装 Python（如果还没装）

打开 python.org，下载最新版 Windows 安装包。

安装时务必勾选 “Add Python to PATH”，然后一路下一步。

第二步：启动一个简单的 HTTP 服务

按 Win + R，输入 cmd 打开命令提示符。

在命令行中输入以下命令并回车：

cmd
python -m http.server 8080
你会看到类似 Serving HTTP on :: port 8080 ... 的提示，说明服务已启动。

第三步：自测

打开台式机上的浏览器（Edge/Chrome 均可），在地址栏输入：

text
http://localhost:8080
如果看到当前目录的文件列表（或一个简单的页面），说明服务本体没问题。

第四步（推荐）：固定台式机的内网 IP

进入你家路由器后台（通常是 192.168.1.1 或 192.168.0.1），找到“DHCP 静态保留”或“IP/MAC 绑定”，把台式机的 IP 固定下来（比如 192.168.1.100）。

这样电脑重启后 IP 不会变，隧道不会断。

⚠️ 注意：这个 http.server 服务窗口不要关闭，它一直开着才能提供网页。如果关了，服务就停了，访问会报 502。

✅ 自测通过标准
浏览器能打开 http://localhost:8080，显示内容。

完成后告诉我，我们进入下一步。

四、模块三：部署隧道连接器（⏳ 待执行，模块二完成后进行）
目标：在台式机上用 Docker 运行 Cloudflare 的隧道客户端，让外网请求能进来。

📝 操作步骤
第一步：安装 Docker Desktop

访问 docker.com/products/docker-desktop/，下载 Windows 版并安装。

安装完成后，启动 Docker Desktop，等待右下角托盘图标显示“Engine running”。

第二步：创建隧道并获取 Token

登录 Cloudflare 控制台，点击左侧 Zero Trust → Networks → Tunnels。

点击“Create a tunnel”，命名（比如 home-tunnel），然后复制生成的 Token（一长串字符）。

第三步：在台式机上运行 Docker 命令

打开命令提示符或 PowerShell，执行以下命令（把 你的TOKEN 替换成刚才复制的真实Token）：

cmd
docker run -d --name cf-tunnel --restart always cloudflare/cloudflared:latest tunnel --no-autoupdate run --token 你的TOKEN --protocol quic
命令中的 --restart always 保证电脑开机后自动启动隧道。

--protocol quic 能提升抗丢包能力，对国内网络更友好。

第四步：独立自测

回到 Cloudflare Tunnels 页面，查看新隧道状态。

如果显示绿色的 HEALTHY，说明连接器部署成功。

如果显示红色或报错，把错误信息截图给我，我们先解决连接器问题，不要急着进行下一步。

🔄 换台式机怎么办？
在新电脑上重新安装 Docker Desktop，再次运行上面的 Docker 命令（用同一个 Token），隧道会自动恢复，域名绑定无需改动。

✅ 自测通过标准
Cloudflare 控制台显示隧道状态为 HEALTHY（绿色）。

完成后告诉我，我们进入下一步。

📝 操作步骤
第一步（可选）：国内访问加速

Cloudflare 默认走国际节点，国内访问可能较慢。

如需提速，可以搜索“Cloudflare 优选IP”工具，配合 Cloudflare for SaaS（需外币卡验证）自行优化。普通个人使用可暂不处理。

第二步（强烈推荐）：添加 Access 访问策略

在 Cloudflare 控制台进入 Zero Trust → Access → Applications。

添加一个自托管应用，把刚才绑定的域名（如 https://nas.905283.xyz）保护起来。

设置策略为 “允许访问的邮箱” 或 “一次性验证码”，这样只有你本人（或你邀请的人）才能看到页面内容。

第三步：本地服务强密码

确保你的本地服务（如 Browser-use 面板）本身设有强密码，防止应用层被暴力破解。

✅ 自测通过标准
用手机流量访问域名，会先跳转到验证码/登录页面，通过后才能看到内容。

如果没设置策略，则直接能看到内容（不推荐长期这样）。
